# مصادر بيانات بحثية عامة لـ ATHENA RF

**تنبيه:** هذه المصادر ليست ملفات متوافقة تلقائيًا مع مجمّع ATHENA. كل مجموعة قد تختلف في جهاز الالتقاط، وعدد الحوامل الفرعية، وتنسيق CSI، وتردد أخذ العينات، والوسوم. يجب مراجعة الترخيص وإضافة محوّل تنسيق واختبار التعميم قبل دمجها مع بيانات ESP32-S3. لا نخلط البيانات الاصطناعية مع نتائج الأداء الحقيقي.

## 1. ESP-Fi HAR — الخيار الأول لتجربة نموذج النشاط
- المستودع العام: https://github.com/AutoSmartGroup/ESP-Fi-HAR
- مجموعة 2026 جُمعت باستخدام ESP32-C3، وتضم 7 أنشطة عبر 4 بيئات داخلية؛ يتضمن المستودع مجموعة البيانات وكود تدريب PyTorch ومرجع الترخيص.
- الترخيص المذكور للبيانات CC BY 4.0؛ احتفظ بالإسناد عند إعادة الاستخدام.
- التشغيل مع ATHENA: نزّل ZIP وفكّه، ثم شغّل `IMPORT-ESP-FI-HAR.bat` وأدخل مسار المجلد. يحوّل المستورد صفوف CSI إلى 64 ميزة زمنية قابلة لاستخدام `ml/train.py`.
- القيد: بيانات C3 ليست مطابقة تمامًا لإشارة S3، نقطة الوصول، الهوائي، القناة، وتردد أخذ العينات. استخدمها كبداية/مقارنة؛ سجّل بيانات S3 الخاصة بك لتقييم الأداء الحقيقي.

## 2. EHUNAM — العدّ والتعرف على النشاط
- الورقة المفتوحة: https://www.nature.com/articles/s41597-025-06238-4
- البيانات: https://doi.org/10.6084/m9.figshare.28541225
- مجموعة متعددة المهام تشمل عدّ الأشخاص والتعرف على النشاط، عبر 8 بيئات و23 يومًا و21 مشاركًا؛ حجمها المنشور نحو 72 GB، لذلك لم ندمجها في ملف المشروع المضغوط.
- اعتمدت إعدادات الالتقاط على معدات مختلفة (منها Broadcom/Atheros وNexmon/Atheros CSI Tool)، ولذلك تحتاج إلى محول تنسيق وتقييم نقل المجال قبل استخدامها مع بيانات ESP32-S3.

## 3. CSI-Bench — مهام استشعار متعددة
- الصفحة/المستودع: https://github.com/johannayara/CSI-Bench
- يضم مهامًا منشورة لاستكشاف التعرف على النشاط، كشف السقوط، كشف التنفس، تقدير الموقع، القرب، والتعرف على مصدر الحركة/الأشخاص.
- مفيد لمقارنة معماريات MLP وLSTM وCNN وTransformer على مجموعات قياس محددة.
- ليس بديلًا عن اختبار ESP32-S3 في الغرفة الفعلية. راجع README والترخيص وروابط بيانات كل مهمة قبل التنزيل.

## 4. WiRe-Breath — التنفس
- المستودع: https://github.com/Yunpeng-Ge/WiRe-Breath
- عمل بحثي عن متابعة التنفس عبر Wi-Fi مع تسميات مرجعية للتقييم.
- يستخدم لتطوير/مقارنة خوارزمية التنفس فقط، لا لإثبات قياس النبض، ولا لادعاء صلاحية طبية.

## 5. NIST BreatheSmart — بيانات مرجعية للتنفس
- صفحة مجموعة البيانات: https://catalog.data.gov/dataset/raw-data-used-to-investigate-the-use-of-wi-fi-signals-to-monitor-human-respiratory-motion
- بيانات CSI مركبة من دمية تنفّس تشريحية، وليست مجموعة بشرية متنوعة. مناسبة لإعادة بناء التحليل المنشور وتجارب الخوارزميات، لكنها لا تثبت الأداء على أشخاص حقيقيين.

## 6. مجموعات نشاط وإشغال عامة
- WiPE-FaLl: https://researchdata.gla.ac.uk/1623/
- Multi-Person Occupancy Dataset: https://researchdata.gla.ac.uk/1151/
- Activity and Localization Dataset: https://researchdata.gla.ac.uk/1283/
- UT-HAR: https://drive.google.com/drive/folders/1R0R8SlVbLI1iUFQCzh_mH90H_4CW2iwt

هذه الروابط وردت ضمن ورقة تقييم منشورة عام 2026 حول مجموعات CSI العامة. تحقق من طريقة الوصول والترخيص والتنسيق الحالي لدى كل مستودع.

## طريقة الاستخدام الموصى بها
1. استخدم هذه المجموعات لقراءة الأبحاث، ووضع خط أساس، وفهم حدود التعميم.
2. اجمع تسجيلات موسومة من لوحة ESP32-S3 الفعلية عبر واجهة ATHENA؛ نفس الجهاز/الهوائي والقناة والغرفة المستهدفة مهمة.
3. لا تخلط مباشرة متجهات مستخرجة من جهاز مختلف مع جلسات ESP32-S3 دون محوّل وقياس أثر اختلاف المجال.
4. احجز أشخاصًا/غرفًا/جلسات كاملة للاختبار إن أمكن؛ لا تقسّم الإطارات المتجاورة من التسجيل نفسه عشوائيًا بين التدريب والاختبار.
5. احتفظ ببيانات مرجعية مستقلة لعدد الأشخاص والموقع والوضعية والتنفس إن أردت تقييم هذه المهام.
