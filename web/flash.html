ATHENA RFESP32-S3 WEB FLASHER
HARDWARE SETUP / 01

تفليش لوحة ESP32-S3 من المتصفح

لا تحتاج إلى تثبيت ESP-IDF على الكمبيوتر. استخدم Chrome أو Edge، وكابل USB ينقل البيانات. يجب أن يكون Firmware المبني من GitHub Actions موجودًا في مجلد web/firmware.

✓ الهدف محددESP32-S3 فقط
✓ إعداد الاتصال لاحقًابوابة إعداد عبر Wi-Fi بعد التفليش
✓ الاستدلال على الكمبيوترملف نموذج ML لا يُفلّش إلى اللوحة
المتصفح لا يدعم Web Serial. افتح هذه الصفحة من Chrome أو Edge على الكمبيوتر، وعلى localhost أو HTTPS.
يتم التحقق من وجود Firmware.

أغلق Arduino Serial Monitor وأي برنامج يستخدم COM قبل بدء التفليش. لا تفصل USB حتى تنتهي العملية. التفليش قد يمسح البرنامج والإعدادات القديمة على اللوحة.

بعد التفليش

إعداد Wi-Fi والكمبيوتر

  1. أعد تشغيل اللوحة، ثم ابحث عن شبكة ATHENA-RF-Setup.
  2. اتصل بها بكلمة المرور athena1234.
  3. افتح http://192.168.4.1 في المتصفح.
  4. أدخل بيانات شبكة 2.4 GHz، وعنوان IPv4 للكمبيوتر الذي يشغّل ATHENA RF، والمنفذ 5005.
  5. بعد الحفظ، أعد الكمبيوتر إلى شبكته الأصلية وافتح لوحة ATHENA RF. اسمح بمرور UDP الوارد على المنفذ 5005 في Windows Firewall.
العداد سيبقى صفرًا إلى أن تتصل اللوحة بالشبكة الصحيحة وتبدأ إرسال CSI حقيقي. نجاح التفليش وحده لا يثبت وصول الحزم.

توفير الإنترنت

البناء يتم على GitHub Actions بدل تنزيل ESP-IDF كاملًا إلى جهازك. يحتاج المتصفح إلى تحميل مكتبة التفليش من CDN عند فتح الصفحة، كما تحتاج لتنزيل ملف Firmware الناتج مرة واحدة. لا ترفع كلمة مرور Wi-Fi إلى مستودع GitHub.
